# earthai

Train a GAN on satellite cloud imagery so it learns the space of plausible skies,
then explore and steer its latent space to generate new skies and smooth
morphing animations between them.

The plan, decisions, and phase checklist live in the tracking issue:
https://github.com/JDerekLomas/earthai/issues/1

## Layout

```
scripts/      data pipeline, training, latent tools (CLI, one job per script)
explore/      interactive latent explorer (sliders, directions, record animation)
notebooks/    scratch experiments
data/         tiles and packed datasets (gitignored, regenerated by scripts)
runs/         checkpoints, sample grids, logs (gitignored)
```

## Setup (Apple Silicon, uses Metal via PyTorch MPS)

```
uv venv --python 3.12
source .venv/bin/activate
uv pip install -e ".[explore]"
python -c "import torch; print(torch.backends.mps.is_available())"   # expect True
```

## Pipeline at a glance

1. `scripts/fetch_tiles.py`   pull MODIS/VIIRS true-colour tiles (NASA GIBS) for chosen cloud regimes
2. `scripts/build_dataset.py` filter, crop, dedupe, pack into a training set
3. `scripts/train.py`         train the GAN, write checkpoints and sample grids
4. `scripts/latent.py`        sample, interpolate, find directions, render video
5. `explore/app.py`           local UI to drive the latent space live

Each step is documented in the tracking issue as it lands.
